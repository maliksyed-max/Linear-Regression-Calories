# Calories Consumed vs Weight Gained

## 📌 About the Project

This project analyzes the relationship between daily calorie consumption and weight gained using Python. Exploratory Data Analysis (EDA) techniques are used to understand the dataset, examine statistical properties, and identify patterns between calorie intake and weight gain.

## 🎯 Objectives

- Analyze the relationship between calorie consumption and weight gained.
- Explore the structure and characteristics of the dataset.
- Calculate descriptive statistics.
- Understand the distribution of calorie consumption and weight gain.
- Identify useful patterns for further regression analysis.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📊 Dataset

The dataset contains two main variables:

- `wt_gained` — Weight gained in grams.
- `cal_consumed` — Calories consumed per day.

## 🔎 Methodology

1. Load the calories dataset.
2. Assign meaningful column names.
3. Inspect the first few records.
4. Check data types.
5. Generate summary statistics.
6. Calculate mean values.
7. Analyze the relationship between calories consumed and weight gained.
8. Use the findings as a basis for further regression analysis.

## 📈 Analysis

The project focuses on understanding whether calorie consumption has a measurable relationship with weight gain and provides a foundation for applying Simple Linear Regression.

## 📂 Project Files

- `Linear Regression calory.py` — Python implementation for data loading and exploratory analysis.
- `calories_consumed.xlsx` — Dataset containing calorie consumption and weight gain data.

## ▶️ How to Run

Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn openpyxl
```

Run the program:
```
python "Linear Regression calory.py"
```
